## 使用说明

1. 每条语令都记录前端日志与后端 JSON 返回。
2. 对于需要确认弹窗的语令，记录“确认前/确认后”两个状态。
3. Android 与 Web 对照时，`intent/table_no/applied/message/ui_action` 必须一致。
