# 易点点使用说明

一句话：先录菜，再点菜，最后买单打印。

## 1. 第一次使用

1. 打开“易点点”。
2. 输入手机号，点“发送验证码”。
3. 收到短信后，输入 6 位验证码。
4. 点“登录/注册”。
5. 系统问权限时，按需要选择允许：
   - 麦克风：用于语音点菜。
   - 蓝牙：用于连接小票打印机。
   - 通知：用于接收提醒。
6. 点右上角“个人页”，设置店名。店名会打印在小票上。
7. 点右上角“设置”，先设置桌号、语音、打印机。

## 2. 页面说明

1. 主页面：点菜、看桌台、上菜、删错菜、打印、买单。
2. 菜品录入：录入菜单、查看菜品、删除菜品。
3. 数据查看：看营业额、查历史订单、补打小票。
4. 设置：设置桌号、外卖单、语音语言、打印机。
5. 个人页：改店名、查看账号、退出登录。

## 3. 菜品录入

### 拍照录入菜单

1. 点“菜品录入”。
2. 点“拍照上传菜单”。
3. 对准菜单拍照。
4. 等系统识别。
5. 看到“预录入菜品确认”后，检查菜名和价格。
6. 没问题就点“确认录入”。

### 语音录入菜品

1. 点“菜品录入”。
2. 点“点击开始录入菜品”。
3. 说菜名、价格、分类。
4. 说完后结束录音。
5. 等系统录入完成。

常用说法：

1. “新增菜品牛肉串 3 元。”
2. “新增菜品羊肉串 3 元，分类烧烤。”
3. “新增菜品可乐鸡翅 28 元一份。”
4. “臭豆腐价格改成 7 元。”
5. “修改年糕的分类为烧烤。”
6. “删除菜品牛肉串。”

小提示：

1. 菜名、价格要说清楚。
2. 同一个菜可以说别名，例如“牛肉串，也叫烤牛肉串”。
3. 长按菜品行可以删除菜品，删除前会让你确认。

## 4. 主页面：按屏幕操作

这是不用说话的操作方式。

1. 选桌：左边点桌号，例如 A3。
2. 看订单：选中桌后，右边会显示这桌的菜。
3. 标记上菜：点菜品右边的“待上菜”，会变成“已上菜”。
4. 改回待上菜：再点一次“已上菜”。
5. 删除点错的菜：长按“待上菜”按钮，确认后删除。
6. 打印当前桌：选中桌后点“打印”。
7. 买单：选中桌后点“买单”，核对金额，再确认买单。

注意：

1. 买单前一定要核对菜品和总金额。
2. 买单成功后，这桌会清空。
3. 已买单订单可以到“数据查看”里查询和补打。

## 5. 主页面：语音操作

### 怎么说

1. 说桌号：可以说“A3”，也可以说“3 号桌”。
2. 说菜名：尽量说菜单里的完整菜名。
3. 说数量：说“2 串、3 份、1 瓶”都可以。
4. 说备注：可以说“少辣、不要葱、打包、先不上”。
5. 已经在左边选中桌号时，可以不说桌号；没选桌时，最好带上桌号。
6. 只说“开桌”时，系统会按循环桌规则分配新桌。

### 常用点菜指令

1. “开桌。”
2. “A3 开桌。”
3. “开桌，加 2 串羊肉串，少辣。”
4. “3 号桌加 2 串羊肉串。”
5. “3 号桌加 10 份可乐鸡翅。”
6. “A3 加土豆片 2 份，少辣。”
7. “A3 牛肉串再加 5 串。”
8. “2 号桌和 6 号桌都加 10 串羊肉串。”
9. “外卖 10 份可乐鸡翅。”
10. “打包 2 份臭豆腐。”

### 常用修改指令

1. “3 号桌退 1 串羊肉串。”
2. “3 号桌删除 1 份土豆片。”
3. “A3 加备注少辣。”
4. “A3 备注改成不要葱。”
5. “删除 A3 的备注。”
6. “A3 羊肉串备注不要辣椒。”
7. “删除 A3 羊肉串的备注。”

### 常用结账指令

1. “3 号桌买单。”
2. “A3 买单。”
3. “3 号桌撤桌。”
4. “8 号桌和 9 号桌撤桌。”

买单或撤桌时，系统可能弹出确认窗口。先看清楚桌号和金额，再点确认。

## 6. 语音按钮和音量键

语音有两种使用方式，可以在“设置 -> 说话方式”里切换。

### 按一次开始，再按一次结束

1. 点语音按钮，开始说话。
2. 说完后，再点一次语音按钮。
3. 系统开始识别和执行。

适合安静环境，手不用一直按着。

### 按住说话，松开结束

1. 按住语音按钮开始说话。
2. 说完后松手。
3. 系统开始识别和执行。

适合门店比较吵的时候。

### 音量键

如果设备支持音量键语音：

1. 音量下键：开始或提交语音。
2. 音量上键：取消本次语音。

实际以当前设备设置为准。

## 7. 桌号和外卖单设置

### 循环桌

1. 点右上角“设置”。
2. 打开“启用循环桌”。
3. 设置桌数，例如 10。
4. 设置字母开头，例如 A。
5. 系统会使用 A1 到 A10。

### 外卖单

1. 点右上角“设置”。
2. 找到“外卖单设置”。
3. 设置外卖单字母开头，例如 W。
4. 外卖订单会用这个字母区分堂食桌号。

## 8. 打印机连接

先在系统蓝牙里配对打印机：

1. 打开设备系统设置。
2. 打开蓝牙。
3. 找到小票打印机并配对。
4. 如果要密码，常见是 0000 或 1234，以打印机说明书为准。

再回到易点点：

1. 点右上角“设置”。
2. 找到“小票打印连接”。
3. 点“申请蓝牙权限”，系统询问时选允许。
4. 点“刷新配对设备”。
5. 选择打印机。
6. 选择票据宽度：58mm 或 80mm。
7. 点“连接选中设备”。
8. 点“打印自检小票”，能出纸就说明连接成功。

常用打印设置：

1. 菜单字号：只改变小票里菜品行的字号。
2. 结账自动打印：打开后，确认买单会自动打印中文账单。
3. 打印样例小票：用来测试小票格式。

## 9. 语音和显示语言

点右上角“设置”，找到“ASR 语种设置”。

语音识别语言：

1. 中文普通话：大多数门店选这个。
2. 中文粤语：说粤语时选这个。
3. 中文四川话：说四川话时选这个。

界面显示语言：

1. 简体中文：默认界面。
2. ئۇيغۇرچە：维语界面。

## 10. 数据查看

1. 点“数据查看”。
2. 看当日营业额。
3. 切换本周或本月，查看周期营业额。
4. 切换每日或每周，查看营收趋势。
5. 查询历史订单：
   - 选择日期。
   - 点“查询历史订单”。
   - 点一条订单，看菜品明细。
   - 需要补打时，点“打印选中单”。

## 11. 危险操作

设置页底部有“危险操作”，平时不要乱点。

1. 清空菜品数据库：会删除所有菜品。
2. 清空当前所有桌：会清空当前正在使用的桌台。

点之前一定确认老板或店长同意。

## 12. 常见问题

### 收不到验证码

1. 检查手机号有没有输错。
2. 等 60 秒后再点“发送验证码”。
3. 检查手机信号和短信拦截。

### 语音没反应

1. 检查是否允许麦克风权限。
2. 到“设置 -> 语音识别语言”选对口音。
3. 靠近设备说话。
4. 环境太吵时，用“按住说话，松开结束”。
5. 网络不好时，识别可能会慢。

### 系统听错了

1. 重说一遍，带上桌号、菜名、数量。
2. 菜名尽量说完整。
3. 容易混的菜，可以在菜品录入时加别名。

### 菜品识别错了

1. 拍照时让菜单放平。
2. 光线要亮，不要反光。
3. 确认录入前先检查价格和菜名。
4. 已录错的菜，可以长按菜品行删除后重新录。

### 打印机找不到

1. 先到系统蓝牙里配对。
2. 确认打印机开机、有电、离设备近。
3. 回易点点点“刷新配对设备”。
4. 还找不到就重启打印机和设备。

### 打印不出纸

1. 看打印机有没有纸。
2. 看蓝牙是否已连接。
3. 点“打印自检小票”测试。
4. 票宽选错时，改成 58 或 80 再试。
5. 仍失败就断开后重新连接。

### 买单后桌台不见了

这是正常的。买单成功后，桌台会释放，订单进入“数据查看 -> 历史订单”。

### 点错菜怎么办

1. 还没买单：在主页面选桌，长按该菜右边的“待上菜”按钮删除。
2. 已买单：去“数据查看 -> 历史订单”查询，只能查看和补打，不能直接改当前桌。

## 13. 打烊对账

1. 点“数据查看”，核对今日营业额。
2. 查询当天历史订单。
3. 需要留底的订单先补打。
4. 确认没有未买单桌台。
5. 关闭打印机或给打印机充电。
