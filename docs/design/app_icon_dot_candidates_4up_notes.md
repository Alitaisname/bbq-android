# App 图标候选（4 选 1）- “点”字版

对应图：`docs/design/app_icon_dot_candidates_4up.png`

设计约束（已按要求）：

1. 结构基于上一版第一排第 3 个（徽章式主图形）。
2. 将中心字形从 `Y` 替换为 `点`。
3. 字体优先使用商标同款风格 `ZCOOL KuaiLe`。
4. 主色调分别采用：
   - A 组：接近上一版第一排第 2 个（青绿偏清爽）。
   - B 组：接近上一版第二排第 3 个（青绿偏稳重）。

四个版本差异：

1. `A1`：清爽青绿，字形偏深青。
2. `A2`：清爽青绿 + 轻微高光，中心“点”字色值为 `#1dc172`。
3. `B1`：稳重青绿，字形偏深蓝青。
4. `B2`：稳重青绿，字形偏品牌绿。

已选定：

1. `A2` 作为 App 最终图标方案。
2. “点”字内部颜色：`#1dc172`。
3. 图标整体采用蓝青渐变底色（蓝色部分作为整体图标），并去除“点”字下方灰色圆圈阴影。
4. `app_icon_a2_single.png` 作为整图直接用于 launcher 图标（不再拆分“整图=前景/背景”渲染逻辑）。
