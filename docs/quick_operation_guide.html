退菜 / 删除 / 备注

  • 退菜：3号桌退1串羊肉串
  • 备注：A3备注改成不要葱
  • 删备注：删除A3的备注
  • 屏幕删除：选桌后长按“待上菜”

语音按键方式

  • 按一次开始，再按一次结束。
  • 按住说话，松开后提交。
  • 音量下键：开始或提交语音。
  • 音量上键：取消本次语音。

屏幕按钮

  • 主页面：选桌、上菜、打印、买单。
  • 菜品录入：拍照上传菜单。
  • 数据查看：历史订单、补打小票。
  • 买单前先核对金额。
