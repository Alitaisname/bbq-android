## 统一要求

1. 每张图附加：设备型号、方向、分辨率、时间戳。
2. Android V2 与 Web 基线按同一数据状态截图对比。
3. 差异超过以下任一条件视为失败：
   - 主结构变更
   - 关键可点击区域位置偏移
   - 关键文字截断或重叠
