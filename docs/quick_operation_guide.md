# 易点点关键操作速查

只记一句话：说清“桌号 + 动作 + 菜名 + 数量 + 备注”。

## 1. 开桌

1. 自动开新桌：`开桌`
2. 指定桌开桌：`A3开桌`
3. 开桌并点菜：`开桌，加2串羊肉串，少辣`

## 2. 点菜 / 加菜

1. 单桌加菜：`3号桌加2串羊肉串`
2. 单桌加多份：`3号桌加10份可乐鸡翅`
3. 带备注点菜：`A3加土豆片2份，少辣`
4. 多桌同加：`2号桌和6号桌都加10串羊肉串`

## 3. 退菜 / 删除

1. 退菜：`3号桌退1串羊肉串`
2. 删除菜品：`3号桌删除1份土豆片`
3. 屏幕删除：主页面选桌后，长按菜品右侧“待上菜”，确认删除。

## 4. 备注

1. 加整单备注：`A3加备注少辣`
2. 改整单备注：`A3备注改成不要葱`
3. 删除整单备注：`删除A3的备注`
4. 加菜品备注：`A3羊肉串备注不要辣椒`
5. 删除菜品备注：`删除A3羊肉串的备注`

## 5. 外卖 / 打包

1. 外卖单：`外卖10份可乐鸡翅`
2. 打包单：`打包2份臭豆腐`
3. 外卖单号设置：右上角“设置” -> “外卖单设置” -> 设置外卖单字母开头，例如 `W`。

## 6. 买单 / 撤桌

1. 买单：`3号桌买单`
2. 撤桌：`3号桌撤桌`
3. 多桌撤桌：`8号桌和9号桌撤桌`
4. 屏幕买单：主页面选桌 -> 点“买单” -> 核对金额 -> 确认。

## 7. 常用屏幕按钮

1. 主页面：选桌、标记上菜、打印、买单。
2. 菜品录入：拍照上传菜单、确认录入。
3. 设置：设置循环桌、外卖单、语音语言、打印机。
4. 数据查看：看营业额、查历史订单、补打小票。

## 8. 按键方式

1. 按一次开始，再按一次结束：点语音按钮开始说话，说完再点一次提交。
2. 按住说话，松开结束：按住语音按钮说话，松开后提交。
3. 音量下键：开始语音或提交语音。
4. 音量上键：取消本次语音。
5. 设置位置：右上角“设置” -> “说话方式”。
